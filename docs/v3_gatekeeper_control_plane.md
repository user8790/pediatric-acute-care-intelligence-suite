# v3 AHA Gatekeeper Control Plane

Gatekeeper uses synthetic demonstration data and is not validated for clinical decision-making.

## Purpose

The AHA Gatekeeper Control Plane governs direct linkages, calculated metrics, predictive assets, warning logic, scenario models, coefficients, open-data feeds, quality rules, panels, cohorts, refresh jobs, validation evidence, release notes, rollback, and acknowledgements.

## Modes

- Executive lite: stoplight summaries for source readiness, metric definitions, warning burden, and active reviews.
- Technical deep: registries, model cards, dependency graph, audit events, scenario register, issue queue, approval workflow, and writeback contract.

## Public Showcase Behavior

The showcase exposes Gatekeeper as a public product area. The internal Walkthrough remains hidden from public navigation.
