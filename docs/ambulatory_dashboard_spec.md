# Ambulatory Dashboard Spec

## Mission Control

Operational question: where is access pressure accumulating, and which capacity choices move it?

KPI set:

- Referral demand.
- Waitlist size and aging.
- Time to first appointment.
- Third next available appointment.
- Follow-up backlog.
- No-show/late-cancel risk.
- Capacity utilization.
- Demand-capacity gap.

## Detail Modules

- Referral and triage intelligence.
- Waitlist and access.
- Clinic template and slot utilization.
- No-show and late-cancel intelligence.
- Follow-up reliability.
- Diagnostic and procedural dependencies.
- Virtual care and travel-burden lens.
- Ambulatory-to-inpatient link.

Patient-level displays are avoided by default. Cohorts and programs are the primary display level.
