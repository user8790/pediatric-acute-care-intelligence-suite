# Ambulatory Showcase Notes

The ambulatory access views are implemented in the React app as aggregate modules:

- Executive access mission control
- Referral and triage intelligence
- Waitlist and access
- Clinic template and slot utilization
- No-show and late-cancel intelligence
- Follow-up reliability
- Diagnostic and procedural queue dependencies
- Virtual care and travel-burden lens
- Ambulatory-to-inpatient link
