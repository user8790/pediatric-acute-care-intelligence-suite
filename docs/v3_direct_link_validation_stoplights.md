# v3 Direct-Link Validation Stoplights

The stoplight layer uses synthetic demonstration data and is not validated for clinical decision-making.

## Required Checks

Each source shows:

- Source view present.
- Field populated.
- Freshness.
- Row count.
- Timestamp logic.
- Referential integrity.
- Metric definition approved.
- Small-cell suppression.
- Overall readiness.

## Use

Public panels surface ready, review, or blocked state. Review state does not mean data is wrong; it means the source owner or metric owner must complete validation before operational reliance.
