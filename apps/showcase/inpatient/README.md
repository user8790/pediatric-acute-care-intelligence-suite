# Inpatient Showcase Notes

The inpatient command centre views are implemented in the React app as aggregate modules:

- Executive mission control
- Bed flow and census
- ED-to-inpatient pressure
- Procedural/PACU impact proxy
- PICU/NICU high-resource pressure
- Staffing and workload
- Synthetic safety and reliability signals
- Discharge barriers
- Provincial pediatric network lens
